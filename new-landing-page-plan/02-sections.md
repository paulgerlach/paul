# Phase 2: Sections

Static markup and the design's CSS, every block in its server state (what reduced motion and no JS show). Section ids and labels as in the design (`si-h1`, `vn-h`, `doppelpflege` / `dp-h`, `fl-h`, `vt-h`, `go-h`, `tm-h2`, `faq-h2`), except the `#start` anchor, which moves from the hero to the closing card (README, Signup). Every text from `content.ts`, the FAQ from `load`. The design's CSS moves into each component's `<style>`; the classes of `#pg-common-css` that a section uses are ported with it (as `/sicherheit` did), not into a global sheet.
