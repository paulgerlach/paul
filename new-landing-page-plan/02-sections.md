# Phase 2: Sections

Static markup and CSS of every section, ported from `#fk-css` and the used parts of `#pg-common-css`, with the `fk-`/`pg-` prefixes dropped where the component's scope makes the class unique. Section heads use the shared `SectionHead` (pill with icon, H2 with the muted second part). Icons through `components/Icon.svelte` (phase 1.4). Every revealable element keeps the design's `rv` class for phase 3.

**Every animated block renders its end state on the server**: revealed content is visible, the hero chart shows Heizung with its bars and "131", tab 1 is selected with its bars filled, the five-step line is filled and the dots are accent. So no-JS visitors and reduced motion get a complete page, and phase 3 only adds motion on top.

Layout basics from the design: `.dm-in` is `max-width: 1240px` with `padding-inline: clamp(16px, 4vw, 40px)`, the same as the landing `.wrap` (check the padding and use `.wrap`). Sections are `.pg-sec`: `padding: 104px 0` (72 px below 640), `border-top: 1px solid var(--hair)`, every second one `.alt` on `--bg`. Grids start `52px` below their head.
