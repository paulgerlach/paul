# Phase 2: Sections

Static markup and CSS of every section, ported from `#ar-css` with the `ar-` prefix dropped where the component's scope makes the class unique. Icons: the feature cards' inline stroke SVGs become `StrokeIcon` paths in `pages/vorgehen/icons.ts`, drawn by `components/Icon.svelte`. Eyebrows use `Eyebrow` (phase 1.6). Every revealable element keeps the design's `rv` class for phase 3.

**Every animated block renders its end state on the server**: revealed content is visible, the wide image isn't zoomed, step 1 is selected with its picture and chip shown, the day count shows the server's number. So no-JS visitors and reduced motion get a complete page, and phase 3 only adds motion on top.

Layout basics from the design: `.dm-in` is `max-width: 1280px` on this page (wider than the other landing pages' `.wrap`; give the page's sections their own inner width rather than changing `.wrap`). Sections are `.ar-sec`: `padding: clamp(72px, 9vw, 128px) 0 0`, no borders, no alternating backgrounds; the cards carry the tone (`--soft`).

Notes:

- Headings: one `<h1>`; one `<h2>` per section with an id for its `aria-labelledby`; `<h3>` for the feature cards. The design's `#hs-css` H2 rule isn't ported (README, Styling), so the H2s keep `.ar-h2`'s `clamp(30px, 3.6vw, 50px)` at every width, as in the design.
- The figures (stats, count, step numbers) use the Geist Mono stack (phase 1.5) with `font-variant-numeric: tabular-nums` on the count, so a ticking number doesn't change width.
- Non-breaking spaces before `%` and in "14 Tage", "1 bis 2 Stunden" in `content.ts`.
- Links: "Angebot einholen" in the hero is an `<a href="#start">`; the `.ar-link` arrow shifts 3 px on hover.
