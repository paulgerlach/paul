# Phase 2: Sections

Static markup and CSS of every section, ported from the design with its class names shortened to the component's scope (the `sa-` / `kd-` / `kx-` / `hd-` / `pg-` prefixes are dropped where the scope makes them unique). Icons: the design's inline stroke SVGs use `StrokeIcon` (task, pipeline, meter and check icons in `pages/selbstabrechnung/icons.ts`, drawn by `components/Icon.svelte`). Every revealable element keeps the design's `rv` class for phase 3.

**Every animated block below the fold renders its end state on the server**: the task split shows "Selbstabrechnung", the calculator shows the defaults, the data path has no lit station, the sample statement no highlighted key, revealed content is visible. So no-JS visitors and reduced motion get a complete page, and phase 3 only adds motion on top. The exception is the hero card, which is always in view on load: it renders its start state ("Daten kommen", 0/18) so it doesn't flash back after hydration (3.1).

Not ported: the design's dead CSS from an earlier hero (`.sa-feed`, `.sa-ff`, `.sa-fh`, `.sa-ft`, `.sa-live`, `.sa-prog`, `.sa-row`, `.sa-st` and their 640 px rule, none used in the markup).

Notes:

- Section backgrounds follow the design: `pg-sec` on `--paper`, `pg-sec alt` (Calculator, Duties, SampleStatement) on the alternate tone, `.kx` on paper with the dark card inside. Read the exact tokens from `#pg-common-css`.
- Headings: one `<h1>`; one `<h2>` per section (the AllMeters section has two, the big card's and "Von der Ablesung …"); `<h3>` for the duty cards, the two `kx` cards. The task columns' and table's heads are `<b>`/`<th>`, not headings, as designed.
- Numbers use non-breaking spaces before `%` and `€` (the design writes `70&nbsp;%`); keep them in `content.ts` as ` `.
- The `sa-tr` grid at 640 px hides columns 2 and 3; with a `<table>`, hide the `<th>`/`<td>` of those columns (`display: none` keeps them out of the accessibility tree too, which matches what's visible).
- Check at 375 px: the hero card (`.kd-stage` gets `min-height: 276px`, the checks' sublines and the results' "m² · Guthaben" are hidden at 640), the table (3 columns fit), the sample sheet (one column, no QR), the floating CTA's short label.
