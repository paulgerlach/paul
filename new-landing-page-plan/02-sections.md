# Phase 2: Sections

Static markup and the design's CSS, every block in its end state (what reduced motion shows). Section ids and `aria-labelledby` as in the design (`sc-h1`, `sc-ph`, `sc-wh`, `sc-dh`, `sc-fh`), except the `#start` anchor, which moves from the hero to the closing card (README, Signup). Every section's text comes from `content.ts`.
